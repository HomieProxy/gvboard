功能

保留原版的全部能力，补上运营中最常用到的部分

📦

单个可执行文件

用户端、管理端页面编译在程序中，队列与定时任务内置。一个进程，一条命令启动。

🔁

无缝迁移

直接接入原生产库，gvboard migrate 升级结构；节点接口、订阅格式、支付回调保持兼容。

🧾

单账号多订阅

一个账号可购买多个套餐，每个订阅拥有独立的流量、到期时间与订阅链接。

🛡️

订阅风控

按 User-Agent、IP、请求头拦截或记录订阅请求；频率限制、防分享、请求日志与统计。

🧩

插件与主题

Go 内置插件与沙箱运行的 JS 插件，可监听订单、工单等事件；支持安装外部主题。

🗄️

MySQL / PostgreSQL

支持 MySQL 5.7+ / 8.0 与 PostgreSQL 13+，提供 db-convert 一键转换。

✉️

通知

多个 SMTP 故障转移 / 轮询，邮件模板在管理端编辑；Telegram 管理员通知可按话题分组。

🌐

灵活部署

前后端不分离一键运行，或把前端单独放到 CDN / 静态站点；支持多实例。

🧰

完善的管理端

订单补单、订阅管理、节点与权限组、优惠券、礼品卡、公告、工单、知识库、队列监控。

快速安装

Linux 服务器（root）运行安装脚本，支持全新安装、从原 v2board 迁移与升级

bash
mkdir -p /root/gvboard-install && cd /root/gvboard-install
curl -fsSLO https://github.com/gunzi-666/gvboard/releases/latest/download/install.sh
bash install.sh

国内服务器下载慢时：GITHUB_PROXY=https://ghfast.top/ bash install.sh

1. 准备环境空数据库（MySQL utf8mb4 或 PostgreSQL）与 Redis 6.0+
2. 运行脚本按提示填写数据库、Redis、管理员邮箱，自动配置进程守护
3. 反向代理Nginx / 宝塔反代到程序端口，绑定域名与证书

Docker、宝塔面板、手动安装、从原生产库迁移见 部署文档
